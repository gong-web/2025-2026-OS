## 🔬 实验概览

### Lab4: 内核线程管理 ⭐ **当前重点**

#### 📖 实验背景

在实现了物理内存管理和中断处理机制后，操作系统的下一个核心功能是**进程管理**。本实验通过实现内核线程（Kernel Thread），让我们深入理解操作系统如何管理执行流，包括进程控制块（PCB）的维护、线程的创建与销毁、以及最核心的上下文切换机制。

#### 🎯 实验目标

1.  **理解进程控制块 (PCB)**: 掌握 `proc_struct` 结构体的设计，理解各成员变量（如 `context`, `tf`, `state`）在进程生命周期中的作用。
2.  **实现内核线程创建**: 编写 `do_fork` 函数，掌握如何通过复制父进程状态来创建新线程，并分配内核栈等资源。
3.  **掌握上下文切换**: 深入理解 `switch_to` 汇编函数的底层实现，明白 CPU 寄存器如何在两个线程间保存与恢复。
4.  **理解调度基础**: 实现 `proc_run` 函数，完成从当前进程到目标进程的切换过程。

#### 🔑 核心技术要点

-   **进程控制块初始化 (`alloc_proc`)**:
    -   设计并初始化 `proc_struct`，设置 PID、状态、内核栈等关键信息。
    -   理解 `context`（上下文切换用）与 `trapframe`（中断现场用）的区别与联系。

-   **线程创建 (`do_fork`)**:
    -   实现了类似 Unix `fork` 的逻辑：分配 PID -> 分配 PCB -> 复制父进程信息 -> 设置内核栈 -> 加入调度队列。
    -   确保了每个新线程都有唯一的 PID 和独立的内核栈。

-   **上下文切换 (`switch_to`, `proc_run`)**:
    -   `proc_run`: 负责切换前的准备（如页表切换 `lsatp`）和切换后的收尾。
    -   `switch_to`: 纯汇编实现，利用栈保存 `ra`, `sp`, `s0-s11` 等 Callee-Saved 寄存器，实现了执行流的“瞬移”。

-   **中断与同步 (`local_intr_save/restore`)**:
    -   利用 `sstatus` 寄存器实现了可嵌套的临界区保护，确保进程链表操作和调度过程的原子性。

#### 📊 实验结果

成功创建了 `idleproc`（空闲线程）和 `initproc`（初始化线程）。系统启动后，`initproc` 被调度运行并打印出 "Hello world!!"，随后系统进入空闲循环，验证了线程创建与切换机制的正确性。

```
(THU.CST) os is loading ...
...
++ setup timer interrupts
this initproc, pid = 1, name = "init"
To U: "Hello world!!"
++ setup timer interrupts
100 ticks
...
```

### Lab3: 中断与中断处理
**目标**: 建立完善的中断与异常处理机制，响应硬件事件。
**关键内容**:
-   **中断入口**: 编写 `trapentry.S`，利用 `sscratch` 实现用户栈/内核栈切换，保存 `TrapFrame`。
-   **中断分发**: 实现 `trap_dispatch`，根据 `scause` 区分中断与异常。
-   **时钟中断**: 利用 OpenSBI 接口设置定时器，实现了基于时间片的系统心跳。

---

### Lab2: 物理内存管理
**目标**: 实现功能完备的物理内存管理系统。
**关键内容**:
-   实现了 First-Fit 和 Best-Fit 内存分配算法。
-   深入研究并完整实现了 **SLUB 分配器**，包含快速/慢速路径优化、CPU 本地缓存和批量分配机制。

### Lab1: 系统启动与内核初始化
**目标**: 理解 RISC-V 平台从硬件复位到内核入口的完整启动流程。
**关键内容**:
-   分析 RISC-V 启动链 (0x1000 → 0x80000000 → 0x80200000)。
-   掌握 OpenSBI 固件与内核的交互。
-   实现栈初始化与内核入口点。
