## Lab1 简要概括
本次 Lab1 主要目标：
1. 复现并理解 RISC-V 平台上从复位到内核入口的最小启动路径。
2. 解析 `entry.S` 中栈初始化与跳转 `kern_init()` 的指令级过程。
3. 利用 OpenSBI + QEMU + GDB 逐地址验证控制权转移：0x1000 → 0x80000000 → 0x80200000。
4. 理解链接脚本如何组织 `.text / .data / .bss` 段并支撑 BSS 清零逻辑。
5. 对启动链关键问题（栈建立、内核入口、固件职责、特权级转换）给出可验证答案。

## Lab2 物理内存管理实验

### 团队分工概述

本次Lab2实验采用分工协作方式，三位成员各自负责不同的核心内存管理算法：

#### 📊 郭子涵 (2312145) - Best-Fit PMM
**实现内容：** Lab2练习二Best-Fit物理内存管理器+练习一
- **核心算法：** 最佳适配连续物理内存分配
- **数据结构：** 有序双向链表管理空闲页面
- **功能特性：** 自动内存合并，减少内存碎片
- **代码位置：** `lab2/郭子涵2312145/lab2/kern/mm/` - Best-Fit PMM实现

#### 🏗️ 梁朝阳 (2311561) - Buddy System
**实现内容：** 经典伙伴系统内存管理器（C++实现）
- **核心结构：** 完全二叉树管理内存块，支持2^n大小分配
- **状态管理：** 四态节点（UNUSED/USED/SPLIT/FULL）精确控制
- **算法特性：** 自动内存合并，最小化外部碎片
- **代码位置：** `lab2/梁朝阳2311561/` - 完整Buddy System实现

#### 🔧 巩岱松 (2312325) - SLUB分配器
**实现内容：** Linux内核级SLUB (Simple List of Unused Blocks) 内存分配器+challenge3
- **核心架构：** 双层缓存设计（CPU本地缓存 + 全局partial链表）
- **预定义缓存：** 8种固定大小对象池（16B-2048B），覆盖内核常用分配
- **性能优化：** 快速路径O(1)分配，CPU本地freelist无锁操作
- **代码位置：** `lab2/巩岱松2312325/` - 完整SLUB实现与测试
