## 📚 当前实验内容

- **lab1**: 操作系统启动


### 快速开始

1. 下载 RISC-V 工具链
2. 安装 QEMU
3. 配置环境变量
4. 开始实验

```bash
# 激活实验环境
source setup_os_env.sh

# 编译并运行实验
cd labcode/lab1
make
make qemu
```
