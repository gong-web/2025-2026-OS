## 三、实验过程与问题分析

### 3.1 初始问题：系统调用未定义

**问题现象**：
```
kernel panic at kern/syscall/syscall.c:114:
    undefined syscall 103, pid = 2, name = sh.
```

**问题分析**：
- 系统调用103对应`SYS_write`
- 用户程序sh需要使用write系统调用进行输出
- 但内核的系统调用表中没有注册文件系统相关的系统调用
- 虽然`kern/fs/sysfile.c`中已实现了所有文件操作函数，但未与系统调用机制连接

**解决方案**：
在`kern/syscall/syscall.c`中添加文件系统系统调用的支持。

### 3.2 第二个问题：标准输入输出未初始化

**问题现象**：
- 第一次修复后，sh程序启动时`load_icode: fd=0`
- 本应是stdin的fd=0被程序文件占用
- 导致sh无法正确读取用户输入

**问题分析**：
- 每个进程应该有标准的文件描述符：
  - fd 0 → stdin（标准输入）
  - fd 1 → stdout（标准输出）
  - fd 2 → stderr（标准错误）
- 但第一个用户进程启动时没有预先打开这些文件描述符
- 当sh程序打开文件时，返回的fd是0（第一个可用的fd）
- 这导致标准输入被程序文件占用，sh无法正常工作

**解决方案**：
在`user_main`函数中，在执行sh之前，先为进程打开标准输入输出设备。

// 打开文件
static int sys_open(uint64_t arg[]) {
    const char *path = (const char *)arg[0];
    uint32_t open_flags = (uint32_t)arg[1];
    return sysfile_open(path, open_flags);
}

// 关闭文件
static int sys_close(uint64_t arg[]) {
    int fd = (int)arg[0];
    return sysfile_close(fd);
}

// 读取文件
static int sys_read(uint64_t arg[]) {
    int fd = (int)arg[0];
    void *base = (void *)arg[1];
    size_t len = (size_t)arg[2];
    return sysfile_read(fd, base, len);
}

// 写入文件
static int sys_write(uint64_t arg[]) {
    int fd = (int)arg[0];
    void *base = (void *)arg[1];
    size_t len = (size_t)arg[2];
    return sysfile_write(fd, base, len);
}

// 移动文件指针
static int sys_seek(uint64_t arg[]) {
    int fd = (int)arg[0];
    off_t pos = (off_t)arg[1];
    int whence = (int)arg[2];
    return sysfile_seek(fd, pos, whence);
}

// 获取文件状态
static int sys_fstat(uint64_t arg[]) {
    int fd = (int)arg[0];
    struct stat *stat = (struct stat *)arg[1];
    return sysfile_fstat(fd, stat);
}

// 同步文件
static int sys_fsync(uint64_t arg[]) {
    int fd = (int)arg[0];
    return sysfile_fsync(fd);
}

// 获取当前工作目录
static int sys_getcwd(uint64_t arg[]) {
    char *buf = (char *)arg[0];
    size_t len = (size_t)arg[1];
    return sysfile_getcwd(buf, len);
}

// 获取目录项
static int sys_getdirentry(uint64_t arg[]) {
    int fd = (int)arg[0];
    struct dirent *direntp = (struct dirent *)arg[1];
    return sysfile_getdirentry(fd, direntp);
}

// 复制文件描述符
static int sys_dup(uint64_t arg[]) {
    int fd1 = (int)arg[0];
    int fd2 = (int)arg[1];
    return sysfile_dup(fd1, fd2);
}

### 4.2 初始化标准输入输出（kern/process/proc.c）

在`user_main`函数中添加标准IO初始化代码：

```c
static int
user_main(void *arg)
{
    /* ============================================
     * 学号：2311561
     * 为第一个用户进程初始化标准输入输出
     * 确保fd 0/1/2分别对应stdin/stdout/stderr
     * ============================================ */
    int fd0, fd1, fd2;
    
    // 打开标准输入 (fd=0)
    fd0 = sysfile_open("stdin:", O_RDONLY);
    if (fd0 < 0) {
        panic("failed to open stdin: %e\n", fd0);
    }
    
    // 打开标准输出 (fd=1)
    fd1 = sysfile_open("stdout:", O_WRONLY);
    if (fd1 < 0) {
        panic("failed to open stdout: %e\n", fd1);
    }
    
    // 打开标准错误输出 (fd=2)，使用stdout设备
    fd2 = sysfile_open("stdout:", O_WRONLY);
    if (fd2 < 0) {
        panic("failed to open stderr: %e\n", fd2);
    }
    
    cprintf("stdin (fd=%d), stdout (fd=%d), stderr (fd=%d) opened.\n", 
            fd0, fd1, fd2);
    /* 学号：2311561 - 标准IO初始化完成 */
    
    KERNEL_EXECVE(sh);
    panic("user_main execve failed.\n");
}
```

**实现要点**：
1. 设备路径格式：ucore的VFS使用`"devname:"`格式访问非挂载设备
2. stdin和stdout在`kern/fs/devs/`中注册为VFS设备
3. 必须按顺序打开，确保fd依次为0、1、2
4. 这些文件描述符会被子进程继承

## 五、关键技术点分析

### 5.1 系统调用机制

**系统调用流程**：
```
用户程序 → syscall(num, args) → ecall指令 → trap处理
    ↓
syscall() → syscalls[num](args) → sys_xxx() → sysfile_xxx()
    ↓
返回用户态
```

**关键点**：
- 系统调用号存储在`a0`寄存器
- 参数通过`a1-a5`寄存器传递
- 返回值通过`a0`寄存器返回

### 5.2 VFS设备访问

**设备命名规则**：
- 非挂载设备：`"devname:"` （如`"stdin:"`、`"stdout:"`）
- 挂载设备：`"devname/path"` （如`"disk0/file.txt"`）
- 绝对路径：`"/path"` （从bootfs根目录开始）
- 相对路径：`"path"` （从当前目录开始）

### 5.3 文件描述符管理

**标准文件描述符**：
- fd 0: stdin（标准输入）
- fd 1: stdout（标准输出）
- fd 2: stderr（标准错误）

**继承机制**：
- fork时，子进程复制父进程的文件描述符表
- exec时，保留已打开的文件描述符

// 内核态处理（kern/syscall/syscall.c）
void syscall(void) {
    int num = tf->gpr.a0;  // 系统调用号
    arg[0] = tf->gpr.a1;   // 参数1: fd
    arg[1] = tf->gpr.a2;   // 参数2: base
    arg[2] = tf->gpr.a3;   // 参数3: len
    tf->gpr.a0 = syscalls[num](arg);  // 执行并返回结果
}
