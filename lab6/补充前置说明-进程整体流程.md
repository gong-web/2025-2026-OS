#### 图1：
```txt
时刻1: proc_init() 执行
┌──────────────────────┐
│  idleproc (PID=0)    │
│  当前正在运行        │
└──────────────────────┘

时刻2: kernel_thread(init_main) 执行
┌──────────────────────┐         ┌──────────────────────┐
│  idleproc (PID=0)    │-------->│  initproc (PID=1)    │
│  创建了子进程        │  创建   │  状态: RUNNABLE       │
└──────────────────────┘         │  在就绪队列中等待     │
                                 └──────────────────────┘

时刻3: schedule() 调度到 initproc，执行 init_main()
┌──────────────────────┐
│  initproc (PID=1)    │  正在执行 init_main()
│  当前正在运行        │
└──────┬───────────────┘
       │
       │ 执行: kernel_thread(user_main)
       ↓
┌──────────────────────┐         ┌──────────────────────┐
│  initproc (PID=1)    │-------->│  新线程 (PID=2)       │
│  创建了子进程        │  创建   │  将执行 user_main     │
└──────────────────────┘         │  状态: RUNNABLE       │
                                 └──────────────────────┘

时刻4: initproc 执行 do_wait()
┌──────────────────────┐
│  initproc (PID=1)    │
│  状态: SLEEPING      │  等待子进程退出
│  在 do_wait 中阻塞   │
└──────────────────────┘

时刻5: schedule() 调度到 PID=2，执行 user_main()
                                 ┌──────────────────────┐
                                 │  线程 (PID=2)         │
                                 │  当前正在运行        │
                                 │  执行 user_main()    │
                                 └──────┬───────────────┘
                                        │
                                        │ 执行: KERNEL_EXECVE(priority)
                                        ↓
                                 ┌──────────────────────┐
                                 │  priority (PID=2)     │
                                 │  变成用户进程！       │
                                 │  运行用户代码        │
                                 └──────────────────────┘

时刻6: priority 用户进程退出
                                 ┌──────────────────────┐
                                 │  priority (PID=2)     │
                                 │  状态: ZOMBIE        │
                                 │  调用 do_exit()      │
                                 └──────────────────────┘
                                        │
                                        │ wakeup_proc(parent)
                                        ↓
┌──────────────────────┐         
│  initproc (PID=1)    │  被唤醒！
│  状态: RUNNABLE      │  从 do_wait 返回
│  回收 PID=2         │  释放其资源
└──────────────────────┘

时刻7: 所有子进程都退出后
┌──────────────────────┐
│  initproc (PID=1)    │
│  do_wait 返回 -1     │  没有子进程了
│  init_main 返回      │  完成使命
└──────────────────────┘
```

#### 图2：

```
┌─────────────────────┐
│   idleproc (PID=0)  │  ← 内核线程（S模式）
│   内核态             │
└──────────┬──────────┘
           │ kernel_thread(init_main)
           ↓
┌─────────────────────┐
│  initproc (PID=1)   │  ← 内核线程（S模式）
│  内核态             │
└──────────┬──────────┘
           │ kernel_thread(user_main)
           ↓
┌─────────────────────┐
│  user_main (PID=2)  │  ← 内核线程（S模式）
│  内核态             │
└──────────┬──────────┘
           │ kernel_execve(priority)
           │ ├─ load_icode()
           │ └─ 清除 SPP 标志位
           ↓
┌─────────────────────┐
│  priority (PID=2)   │  ← 用户进程（U模式）
│  用户态             │  ★ 第一个真正的用户进程！
└─────────────────────┘
```
